# ویدیوهای تبلیغاتی AIFekr — ElevenLabs Ready Templates

این پوشه شامل متن و راهنمای اسکرین‌شات برای هر ۳ نوع ویدیوی ElevenLabs است.

فایل‌ها:
- `01-laptop-showcase/` → قالب "Show on a laptop screen"
- `02-dialogue-voiceover/` → قالب "Compare Voices" (اسکریپت دیالوگ ۲-۳ نفره)
- `03-phone-mockup/` → قالب "Showcase your app" (موبایل موک‌آپ)

هر پوشه یک `checklist.md` دارد که می‌گوید دقیقاً از کدام صفحه‌ی داشبورد (وقتی لاگین کرده‌اید) اسکرین‌شات بگیرید و با چه Prompt آپلودش کنید.
