# Template 1 — Show on a laptop screen

This tool places your screenshot on a laptop/monitor in a realistic scene.
Take 4-5 separate screenshots from the dashboard (each one = one run of the tool = one scene in the final video).

## Screenshots to capture (in order of priority)

| # | Screen | Approx. path | Tip for a clean shot |
|---|--------|--------------|------------------------|
| 1 | AI Chat | `/chat` | Show a short, real conversation with a good answer on screen — not an empty chat |
| 2 | Image generation | `/chat` or `/tools/image` | Make sure a high-quality generated image is visible in the result |
| 3 | Business dashboard / CEO Orchestrator | `/business` or `/boardroom` | Charts and KPIs should be full and colorful |
| 4 | CRM (sales pipeline) | `/crm` or `/crm/pipeline` | Show several leads/deals across the kanban columns |
| 5 | SEO agents | `/seo` or `/agents/seo` | Show analysis results or keyword data |

Tip: before screenshotting, resize the browser window to 16:9 (e.g. 1600×900) so it fits naturally on a monitor, and if test data is sparse, add a few sample items (leads, messages, images) so the screen doesn't look empty.

## Suggested prompt for each scene

Enter these in the "Describe the phone and setting" field for each screenshot:

1. **Chat** → `laptop on a modern minimalist desk, soft morning light, coffee cup beside it, entrepreneur working from home`
2. **Image generation** → `monitor in a creative studio, professional photographer's desk, warm ambient lighting`
3. **Business dashboard** → `laptop in a modern startup office, glass walls, natural daylight, small team working in background`
4. **CRM** → `monitor on a sales manager's desk, headset nearby, bright open-plan office`
5. **SEO** → `laptop in a cozy home office, bookshelf background, focused solo founder`
