# AIFekr SEO audit — 22 October 2026

## Evidence and priority

Live HTML was inspected for 16 public/interactive URLs, plus robots.txt and sitemap.xml. Snapshot: `seo-before.json` (local diagnostic artifact). This is a technical/content audit; Search Console query, backlink and Core Web Vitals field data were not available. Fetch duration is not a Lighthouse or field-performance score.

The full pre-release sitemap crawl covered 156 unique URLs: all returned 200 and had titles, but their canonical origins inherited the local build address. All four homepage language versions had two H1s.

Production verification after release `c58bb97`: **164 sitemap URLs**, zero non-200 responses, zero missing/wrong-origin canonicals, zero missing/duplicate H1s and zero noindex URLs in sitemap. Local snapshot: `seo-crawl-after.json`. Guest session reports `OpenAI · GPT-5 mini`. Direct streaming smoke test returned 200 and a real two-character response (22 total tokens, estimated $0.000023); the audit crawl itself makes no paid generation requests. TypeScript, scoped lint, production build and 18 focused SEO/chat tests passed.

| Priority | Before | Implemented |
|---|---|---|
| Critical | Production canonicals, language alternates and sitemap used `http://localhost:3003` from the local build environment | Public site identity fixed to `https://aifekr.com`; regression test covers local build variables |
| High | FIT had English-only metadata and no canonical | Localized metadata and self-canonical/hreflang for all supported languages; FIT added to sitemap |
| High | Public interactive chat and selection screens had no explicit indexing policy | `noindex` on explore/chat/start/choose-plan and admin; authenticated content remains access controlled |
| Medium | Homepage had two H1s after embedding pricing | Embedded plan section uses H2; standalone pricing keeps its own H1 |
| Medium | Generic feature titles did not explain search intent | Persian/English search-target titles/descriptions for homepage, assistant, business, students, fitness and pricing |
| Medium | No focused public AI chat explainer | `/ai-chat` with localized explanatory content, a real FAQ answer, signup flow, internal links and canonical/hreflang |
| Medium | Sitemap advertised unrelated editorial dates on homepage/pricing | Editorial lastmod restricted to guide detail URLs where the content date applies |

## Follow-up measurement

1. Verify domain ownership in Google Search Console using the existing owner account; submit `https://aifekr.com/sitemap.xml`. Inspect `/`, `/en`, `/ai-chat`, `/en/ai-chat`, `/fit` and `/pricing` for Google-selected canonical and indexability. This audit did not submit to an unconnected account.
2. First 30 days: monitor sitemap processing, excluded pages, canonical selection, crawl errors and impressions by Persian/English query. Request indexing for priority updated pages after the live canonical check.
3. Days 30–60: improve pages with impressions but low CTR using actual query data. Publish original, useful tutorials tied to real product workflows; link them to the relevant feature page.
4. Days 60–90: compare non-brand clicks, qualified signups and purchases by landing page. Measure mobile Core Web Vitals with real field data and optimize the slowest templates. Build editorial mentions and real partnerships, not paid link schemes.

First place in Google cannot be promised. Indexing and rank changes depend on Google, competition and demonstrated page/site value. Technical fixes are prerequisites, not proof of a ranking gain.
