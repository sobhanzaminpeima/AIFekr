# مسترپرامپت ممیزی و اجرای سئوی AIFekr

نقش: متخصص سئوی فنی، استراتژی محتوا و توسعهٔ Next.js. هدف، افزایش ترافیک مرتبط و تبدیل فارسی و انگلیسی برای https://aifekr.com است؛ رتبهٔ یک را تضمین نکن.

۱. ابتدا HTML واقعی و کد را بررسی کن: وضعیت HTTP، ریدایرکت، عنوان و توضیحات، H1/H2، canonical، hreflang، robots، sitemap، دادهٔ ساختاریافته، لینک‌های داخلی، تصاویر، موبایل، زمان پاسخ و خطاهای زبان. یافته را با URL و شواهد ثبت کن؛ حدس را از اندازه‌گیری جدا کن.

۲. صفحات عمومی را از حساب‌ها، چت خصوصی، ادمین، پرداخت و پیش‌نمایش تعاملی جدا کن. دادهٔ کاربر نباید ایندکس یا در اسکیما افشا شود. noindex جای کنترل دسترسی را نمی‌گیرد.

۳. برای هر صفحه یک هدف جستجو و خوشهٔ کلمات فارسی/انگلیسی تعیین کن: چت هوش مصنوعی، ابزار هوش مصنوعی کسب‌وکار، دستیار دانشجویی، مربی ورزشی هوش مصنوعی و تولید محتوای ویدیویی. هم‌پوشانی صفحات را کم کن. حجم جستجو، رتبه و رقابت را بدون دادهٔ معتبر جعل نکن. ترجمهٔ تحت‌اللفظی جای نیت جستجوی محلی را نمی‌گیرد.

۴. عنوان، توضیح، تیتر و متن قابل مشاهدهٔ هر صفحه را طبیعی و مفید اصلاح کن؛ keyword stuffing، صفحات درگاه، وعدهٔ رتبه، نظر/امتیاز جعلی و قابلیت غیرواقعی ممنوع. AIFekr را به‌عنوان سرویس مستقل معرفی کن؛ فقط مدل واقعاً متصل را نام ببر.

۵. برای هر زبان URL پایدار، canonical خودارجاع، hreflang متقابل و x-default درست بساز. sitemap فقط URLهای canonical قابل ایندکس و با lastmod واقعی داشته باشد. صفحات فاقد ترجمه نباید نسخهٔ زبان جعلی بسازند.

۶. اصلاحات کم‌ریسک را اجرا و تست کن؛ پرداخت، مالکیت داده‌ها و دسترسی‌های فعلی را حفظ کن. خروجی شامل گزارش قبل/بعد، نقشهٔ کلمات، تغییرات، تست و محدودیت باشد. بدون کلید یا دادهٔ خصوصی گزارش بده.

۷. پس از build و تست، GitHub و سرور را با بکاپ و rollback به‌روز کن. HTTP، canonical، hreflang و noindex دامنهٔ واقعی را دوباره بررسی کن. اقدام‌های نیازمند مالکیت Search Console و برنامهٔ سنجش ۳۰/۶۰/۹۰ روزه را مشخص کن؛ هیچ رتبه یا درآمدی را تضمین نکن.
