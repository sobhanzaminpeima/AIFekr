# Navigation Map

## Before
Sidebar (all users): Home · FIT · Chat · Student · [Business Doctor card · Sales/CRM dept · Marketing dept · Finance dept · Strategy dept] · Create (Agents, Gallery, Video Factory, Voice Studio, PLAY, Startup) · SEO Intelligence card · More (Tools ×6, Assistants ×7) · Projects · History · footer (credits, packs, plans, referral, settings).

## After (when a workspace is chosen)
1. Workspace switcher (top): current workspace, list of 6 workspaces + "All tools (full menu)", note that plan/credits/access do not change.
2. Workspace groups (2–5 short groups, plain-language titles).
3. "All tools" toggle → the full classic menu, unchanged.
4. Home · FIT · Chat · Student · pending payments (unchanged).
5. Projects · History · footer (unchanged).

With no workspace chosen: identical to Before, plus the switcher and a one-line suggestion.

## Search
Ctrl K / mobile search: names + fa/en goal synonyms (`SEARCH_KEYWORDS`), ranked, real routes only.
