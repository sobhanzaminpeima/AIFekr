# Video Factory packages and credit protection

Packages use the existing Package, BillingQuote, Payment and AI credit ledger. VIDEO_FACTORY purchases grant personal AIFekr credits without replacing another subscription. The immutable verified payment snapshot holds videoCount, videoSeconds and videoMaxSeconds; package edits do not change historical purchases. Production claims quota under the account write lock and records paymentId and duration in the job policy. Failed/cancelled jobs release count and minutes. Every video is at most 480 seconds when package authorization is required.

Draft proposals (30 days): Starter $29.99 / 3 videos / 18 minutes / 3,000 credits / max 6 minutes; Creator $69.99 / 8 videos / 48 minutes / 7,500 credits / max 8 minutes; Studio $119.99 / 15 videos / 90 minutes / 14,000 credits / max 8 minutes. Credits authorize actual configured generation; quota and sufficient credits are both required. Package credits can be used in the existing AIFekr ledger, so quotas are ceilings, not an unconditional guarantee of a fixed number of premium-model renders.

These are DRAFT planning offers, not verified supplier quotes. The planning worksheet allocates 80 cents production plus 20 cents platform overhead per finished minute; it is deliberately marked unverified. Confirm exact Argon product/model, Opus input/output pricing, Nano Banana image pricing, clip seconds, voice/music, retries, rendering/storage and payment fees before approving commercial rates. Existing per-action rates remain mandatory; any action budget exceeding the retail charge is rejected. No paid request is made by setup.

Technical failure before delivery refunds all reserved credits, including attempted provider work, to the original payer. The platform absorbs incurred provider costs. A transaction claims settledAt once; the refund ledger request ID is unique. User cancellation refunds unused credits. Interrupted browser sessions do not cancel durable server jobs; uncertain submitted external calls are not repeated automatically. Native rendering and assembly are retried within configured limits.

Run node scripts/prepare-video-factory-packages.cjs in the release directory to add missing draft offers, preserve existing offer records, select package authorization and keep factory sales disabled. No schema migration is required. Admin Packages includes VIDEO_FACTORY and explicit quota inputs. The factory previews draft offers; published offers use the existing checkout. Checkout and generation retain VIDEO_FACTORY_SALES_APPROVED, approved tariff and provider gates. Do not enable these without owner authorization and verified rates. YouTube publishing requires channel authorization; monetization approval and earnings are never guaranteed.

Tests: package quota count/time/max duration/expiry, purchase snapshots, failed-job exact-once refund and quota restoration, dedicated provider selection, durable workflow and native FFmpeg. Remotion tests require its optional renderer installation.
