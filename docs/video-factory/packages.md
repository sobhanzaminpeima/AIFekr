# Video Factory packages and credit protection

Packages use the existing Package, BillingQuote, Payment and AI credit ledger. VIDEO_FACTORY purchases grant personal AIFekr credits without replacing another subscription. The immutable verified payment snapshot holds videoCount, videoSeconds and videoMaxSeconds; package edits do not change historical purchases. Production claims quota under the account write lock and records paymentId and duration in the job policy. Failed/cancelled jobs release count and minutes. Every video is at most 480 seconds when package authorization is required.

Draft proposals (30 days, revised 2026-10-19): Starter $69.99 / 3 videos / 18 minutes / 7,000 credits / max 6 minutes; Creator $169.99 / 8 videos / 48 minutes / 17,000 credits / max 8 minutes; Studio $319.99 / 15 videos / 90 minutes / 32,000 credits / max 8 minutes. Credits authorize configured generation; quota and sufficient credits are both required. Package credits can be used in the existing AIFekr ledger, so quotas are ceilings, not an unconditional guarantee of a fixed number of premium-model renders. Jobs shorter than a minute retain the one-minute cost floor.

These are DRAFT planning offers based on official direct API list prices. Argon is removed. Claude Opus 5.5 directs the screenplay; Gemini 3.1 Pro generates validated declarative animation instructions, never executable model-authored JavaScript. Trusted Remotion components animate Nano Banana 2 images; FFmpeg mixes narration, instrumental music, captions and the final output. There are no generated-video clip API calls in IMAGE_MOTION. Eleven v3 supports Persian as well as English, Turkish and German. The deprecated gemini-2.5-flash-image is not selected.

The editable rate card in `src/lib/video-factory/rate-card.json` records official sources and review date. Per output minute it budgets Claude 20k input/6k output tokens at $4/$20 per million, Gemini 16k input/4k output at $2/$12 per million (standard <=200k context), 8 Nano Banana 2 1K images at $0.067 plus image input/text-output tokens, 1k Eleven v3 characters at $0.08 and one minute of music at $0.15. Total supplier allowance: $1.0504/minute. Add 25% failed-work/retry reserve, $0.20/minute AIFekr compute/storage/operations and $0.10/minute provisional Remotion allocation: $1.613/minute before payment fees. Payment allowance is 4% plus $0.30 per transaction. At full package duration, modeled costs are approximately $32.14, $84.53 and $158.27; modeled gross margins exceed 50% for all three proposals. Integer-cent rounding is conservative. Price floor = (cost before payment + fixed fee) / (1 - 0.50 - percentage payment fee), not cost times 1.5. Referrals, FX, taxes and account-specific supplier terms must be reconciled before launch; no universal final margin is claimed.

Usage, retry frequency, payment fees and infrastructure are assumptions, not measured production costs. Remotion's official company automator license is $0.01/render with a $100/month minimum when applicable; $0.10/minute provision assumes 1,000 output minutes/month. Free-license eligibility depends on organization size and terms. Below that volume the allocation must be increased; license approval remains false. Direct supplier rates must not be applied to CodeCraft reseller billing without confirming the reseller's own charges. No paid request is made by setup; API account access, voice selection, licensing and end-to-end paid quality are still unverified.

Admin can edit rates, consumption assumptions, model IDs, fee/reserve/margin settings and sources in the economics panel, and actual provider routing/credentials in API & LLM management. Saving a worksheet model name alone does not change routing. The admin economics POST action REPRICE_DRAFTS updates only unpurchased USD draft offers using saved rates, leaves historical purchases untouched and keeps offers private. Existing per-action budgets remain mandatory. The quote engine recalculates the retail floor from the saved rate card. IMAGE_MOTION limits chapters to 8 shots, narration to 1k characters per output minute, rejects unpriced advanced add-ons and disallows generated clips. Music generation is capped at 5 minutes and looped by FFmpeg for longer outputs.

Official sources: https://www.anthropic.com/claude/opus ; https://ai.google.dev/gemini-api/docs/pricing ; https://elevenlabs.io/pricing/api ; https://elevenlabs.io/docs/help-center/other/what-languages-do-you-support ; https://www.remotion.dev/docs/license/pricing .

Technical failure before delivery refunds all reserved credits, including attempted provider work, to the original payer. The platform absorbs incurred provider costs. A transaction claims settledAt once; the refund ledger request ID is unique. User cancellation refunds unused credits. Interrupted browser sessions do not cancel durable server jobs; uncertain submitted external calls are not repeated automatically. Native rendering and assembly are retried within configured limits.

Run node scripts/prepare-video-factory-packages.cjs only for initial missing draft creation, then node scripts/revise-video-factory-costs.cjs for the revised draft motion pipeline. The revision skips published/purchased offers, registers disabled native providers with environment credential references, records audit entries, disables Argon routes and leaves module, provider approvals, sales and licensing locked. No schema migration is required. Admin Packages includes VIDEO_FACTORY and explicit quota inputs. The factory previews draft offers; published offers use the existing checkout. Checkout and generation retain VIDEO_FACTORY_SALES_APPROVED, approved tariff and provider gates. Do not enable these without owner authorization. YouTube publishing requires channel authorization; monetization approval and earnings are never guaranteed.

Tests: package quota count/time/max duration/expiry, purchase snapshots, failed-job exact-once refund and quota restoration, dedicated provider selection, durable workflow and native FFmpeg. Remotion tests require its optional renderer installation.

## Fixed published retail prices

Currency-specific term totals are stored in `Package.entitlements.fixedPrices` (USD/TRY/EUR minor units; IRT whole toman). Admin Packages has dedicated controls. Landing and workspace use the same published catalog and render the explicit base price when a local fixed price is missing, never a missing-rate placeholder. BillingQuote locks the identical fixed settlement amount and fixed toman accounting value; expired exchange rates cannot alter or block that quote. Legacy plans without fixed local amounts retain existing conversion semantics. The freeze script captures previously recorded rate references once, preserves existing fixed entries and historical payment snapshots, and publishes video package prices. Live exchange-rate refreshes do not change published fixed prices.
