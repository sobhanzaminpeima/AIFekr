# چت AIFekr

### چه کاری می‌کند؟
دستیار عمومی شماست: سؤال بپرسید، متن بنویسید، تحلیل بگیرید. علاوه بر آن حالت‌های تخصصی دارد (دکتر کسب‌وکار، مارکتینگ، مالی، فروش، استارتاپ، حقوقی، منابع انسانی) که لحن و عمق پاسخ را عوض می‌کنند. اگر از آن بخواهید یک پرامپت برای یک AI دیگر بنویسد، پرامپت را در یک کارت جدا و قابل‌کپی می‌دهد.

### کجاست؟
سایدبار، درست زیر «خانه». آدرس مستقیم: `/chat`. تاریخچهٔ مکالمه‌ها پایین‌تر در همان سایدبار می‌ماند و می‌توانید مکالمه‌ها را در پروژه دسته‌بندی کنید.

### انتخاب مدل و هزینه
پیش‌فرض روی «خودکار» است: سیستم بر اساس نوع سؤال بهترین مدل موجود را انتخاب می‌کند و اگر مدلی در دسترس نبود، خودش به مدل بعدی می‌رود. می‌توانید مدل را دستی هم انتخاب کنید. هر پیام اعتبار مصرف می‌کند و مقدارش به مدلی که واقعاً استفاده شده بستگی دارد — اعتبار فقط بعد از پاسخ موفق کم می‌شود.

### زبان
چت به زبانی که شما بنویسید جواب می‌دهد؛ فارسی بپرسید، فارسی می‌گیرید. اگر پاسخی به زبان اشتباه آمد، دوباره بپرسید و اگر تکرار شد، آن را به‌عنوان باگ گزارش بدهید.

# AIFekr Chat

### What it does
Your general assistant: ask questions, draft text, get analysis. It also has expert modes — business doctor, marketing, financial, sales, startup, legal, HR — that change the tone and depth of the answer. If you ask it to write a prompt for another AI, it hands the prompt back in a separate, copyable card.

### Where to find it
In the sidebar, directly under "Home". Direct address: `/chat`. Your conversation history sits further down the same sidebar, and conversations can be grouped into projects.

### Model choice and cost
The default is "auto": the system picks the best available model for the kind of question and falls through to the next one if a provider is unavailable. You can also pick a model by hand. Each message costs credits, scaled to the model actually used — and credits are only deducted after a successful answer.

### Language
Chat replies in whatever language you write in; ask in Persian, get Persian. If an answer comes back in the wrong language, ask again — and if it keeps happening, report it as a bug.

# AIFekr Chat

### Was es leistet
Ihr allgemeiner Assistent: Fragen stellen, Texte entwerfen, Analysen erhalten. Dazu gibt es Expertenmodi — Business Doctor, Marketing, Finanzen, Vertrieb, Startup, Recht, Personal —, die Ton und Tiefe der Antwort verändern. Bitten Sie ihn um einen Prompt für eine andere KI, gibt er diesen in einer eigenen, kopierbaren Karte zurück.

### Wo Sie es finden
In der Seitenleiste direkt unter „Startseite". Direkte Adresse: `/chat`. Ihr Gesprächsverlauf steht weiter unten in derselben Seitenleiste; Gespräche lassen sich in Projekten gruppieren.

### Modellwahl und Kosten
Standard ist „automatisch": Das System wählt je nach Art der Frage das beste verfügbare Modell und wechselt zum nächsten, wenn ein Anbieter nicht erreichbar ist. Sie können das Modell auch selbst wählen. Jede Nachricht kostet Guthaben, abhängig vom tatsächlich genutzten Modell — abgebucht wird erst nach einer erfolgreichen Antwort.

### Sprache
Der Chat antwortet in der Sprache, in der Sie schreiben. Kommt eine Antwort in der falschen Sprache, fragen Sie erneut — und melden Sie es als Fehler, wenn es sich wiederholt.
