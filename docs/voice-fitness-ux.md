# Voice Studio UX and fitness access — 2026-10-28

Detailed reservation/pricing text is collapsed; single-segment text no longer needs a redundant segment selector. Voice cards and headings use a restrained type scale and theme colors. Mobile layout stacks controls without obscuring the editor.

An accessible status card reports queued, actual provider dispatch, validated-audio storage, and ready states. It never invents a completion percentage. Existing idempotency/reservation rules remain. Worker idle checks changed from five seconds to one; completed work immediately drains the next queued job. Provider processing time remains outside AIFekr's control. Approved models compatible with the interface language receive a default selection, preferring a low-latency model where available; users can change it. Project deep links now open the saved project.
