# Vazirmatn font asset

Unmodified variable WOFF2 from the official **v33.003** release:

- Project: https://github.com/rastikerdar/vazirmatn
- Font: https://raw.githubusercontent.com/rastikerdar/vazirmatn/v33.003/fonts/webfonts/Vazirmatn%5Bwght%5D.woff2
- License: `Vazirmatn-OFL.txt` (SIL Open Font License 1.1, preserved in full)
- The existing `Vazirmatn` family and weights 100–900 remain unchanged.

Self-hosting removes the Google Fonts stylesheet dependency and its failure
mode when external font requests are unavailable. No npm dependency was added.
